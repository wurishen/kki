# Pyramid Core Unified v0.3.0

单插件整合版：将现有 BIO（角色生理监测）、柚月の记忆（记忆表格/向量记忆）作为内部引擎随一个扩展加载，并提供统一 Core 事件总线与认知包桥接，专注人类行为模拟（身体/记忆）。

## 安装

只安装本目录对应的一个扩展。不要再单独安装原来的 BIO、柚月 Memory，否则会重复初始化。

## 数据兼容

原两个引擎的代码与主要 localStorage 命名空间保留，目的是尽量兼容已有数据。没有删除原引擎的内部功能。

## 世界书

`worldbooks/` 内保留：
- BIO-人类生理行为模型.json
- 7.3「yuzuki_记忆表格变量」.json

这两个文件作为配套世界书/变量模板随包提供；不会在安装时未经用户确认自动写入酒馆世界书，以避免覆盖现有配置。

## Core

`window.PyramidCore` 提供：
- 统一启动
- 引擎状态检测
- 事件总线
- 当前认知包编译
- Core 状态导出

v0.3 的策略是“单插件 + 内置原引擎 + 统一桥接”，先保证原功能不被重构破坏；后续可继续把共享 State/Event/Prompt 生命周期进一步收敛。
